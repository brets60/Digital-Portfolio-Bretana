# Bretaña — Digital Portfolio

Personal digital portfolio and interactive engineering showcase of **John Michael D. Bretaña** (BSIT 4th Year, Software Engineer & Creative Developer).

## 🚀 Features

- **Next.js 14 App Router & TypeScript**: Fast server-side rendering and client-side interactivity.
- **Three.js & WebGL 3D Particle Field**: Custom canvas particle background and physics interactions.
- **Matter.js Physics Tech Stack**: Interactive draggable 2D physics badges for developer tools and skills.
- **Interactive Terminal**: Custom in-browser CLI terminal for discovering projects and running commands.
- **Bento Grid & Milestones Timeline**: Visual project showcase including Speed Detection CCTV Warning System, Laundry Logistics Platform, and School Event Management.
- **Audio Experience**: Interactive tactile sound effects powered by Web Audio API.
- **Tailwind CSS & Framer Motion**: Smooth motion layout transitions and dark theme aesthetic.

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, Lenis Smooth Scroll
- **3D & Physics**: Three.js, Matter.js, Canvas Confetti
- **Icons**: Lucide React

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/brets60/Digital-Portfolio-Bretana.git
   cd Digital-Portfolio-Bretana
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run development server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) to view the portfolio.

4. **Build for production**:
   ```bash
   npm run build
   npm run start
   ```
